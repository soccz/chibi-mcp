# Official Asset Terms

This document separates the code license from the official chibi-mcp artwork and brand assets. It is an operational policy, not legal advice.

## Scope

These terms apply to official project images and presentation assets, including:

- `assets/`
- `server/chibi_mcp/assets/`
- `vscode-ext/resources/`
- `docs/screenshots/`
- `assets/social-preview.png`
- official `tteoki` / `chibi-mcp` character presentation in README and release assets

The project code remains under [MIT](LICENSE). Official artwork, social previews, character images, option-layer PNGs, names, badges, and release presentation are not automatically relicensed as standalone stock art by the MIT code license.

## Allowed Uses

You may use the official assets to:

- install, run, test, package, and demo chibi-mcp;
- show screenshots or videos of chibi-mcp;
- make a clearly identified fork that preserves attribution and does not imply official endorsement;
- submit bug reports, docs, tutorials, and compatibility notes about chibi-mcp.

## Not Allowed Without Permission

Do not use official assets to:

- claim that a fork, package, marketplace listing, website, or character pack is the official chibi-mcp project;
- remove provenance or attribution from official project artwork;
- sell official assets as a standalone pack, mascot, sticker set, NFT, stock-art bundle, training dataset, or merchandise;
- use official artwork as the primary branding for an unrelated or competing project;
- create confusingly similar release pages, social previews, package names, or marketplace listings;
- submit third-party characters, logos, mascots, screenshots, or fan art as if they were original chibi-mcp assets.

## Forks And Redistribution

Forks are allowed under the code license. Forks should:

- keep the original license and attribution;
- make it clear that they are forks or unofficial variants;
- rename or clearly mark modified artwork if it may confuse users;
- preserve `ASSET_RIGHTS.md`, this file, or an equivalent rights notice.

## Creator Packs

Creator/team packs are separate submissions. A pack author keeps whatever rights they hold, but public submission to this project requires:

- `license`
- `source_rights`
- `rights_owner`
- `asset_origin`
- `permission_scope`
- `no_third_party_ip: true`

Run:

```bash
chibi-pack validate --submission ./my-pack
```

## Copycat Response

If someone copies official assets or creates user confusion, use [docs/COPYCAT_RESPONSE.md](docs/COPYCAT_RESPONSE.md). Keep commit SHAs, file paths, screenshots, release links, marketplace URLs, and package names before sending a takedown or trademark/confusion report.
