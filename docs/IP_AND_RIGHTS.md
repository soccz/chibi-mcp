# IP and Rights Guardrails

`chibi-mcp` is intentionally easy to install and fork, so the realistic
protection strategy is not "stop every copy." The project should make the
official source clear, keep provenance records, reject risky submissions, and
preserve evidence if a takedown or brand-confusion claim is needed later.

This is operational guidance, not legal advice.

## What Can And Cannot Be Protected

- The idea of a local AI coding pet, MCP companion, rice-cake mascot, or
  desktop widget is not enough by itself. Copyright protects original expression,
  not ideas, facts, systems, or methods of operation.
- Original PNG artwork, character expressions, written copy, screenshots, and
  source files can be evidence of original expression.
- `chibi-mcp`, `chibi`, logos, badges, marketplace names, and official release
  presentation are brand signals. Stronger brand protection is a trademark
  decision, not a normal code change.
- A fork is allowed under an open-source code license, but a fork should not
  claim to be the official project or imply endorsement.

Sources:

- U.S. Copyright Office, "What does copyright protect?":
  https://copyright.gov/help/faq/faq-protect.html
- USPTO, "Trademark basics":
  https://www.uspto.gov/trademarks/basics
- USPTO, "Trademark process":
  https://www.uspto.gov/trademarks/basics/trademark-process

## Submission Review Policy

Reject or request changes when a pack includes:

- third-party characters, mascots, logos, UI screenshots, or brand marks without
  permission;
- AI-generated images that imitate a living artist, named studio, known mascot,
  or copyrighted character;
- source files with unclear ownership;
- misleading official/project endorsement claims;
- NSFW or general-audience unsafe content.

Acceptable submissions should include:

- transparent PNGs;
- top-level `license`, `source_rights`, `rights_owner`, `asset_origin`,
  `permission_scope`, and `no_third_party_ip: true` fields;
- source/provenance files if requested during review;
- a local preview generated by `chibi-pack preview`.

## Suggested Future Decisions

Do not implement these without explicit user approval:

- Trademark search and registration for `chibi-mcp`, `chibi`, and any logo.
- Signed asset manifests or release checksums for official packs.
- Private high-resolution source art with lower-resolution runtime PNGs in the
  public package.
- Official marketplace terms for creator submissions.

Creative Commons explains that creators can choose public license conditions
such as attribution, noncommercial use, share-alike, or no-derivatives:
https://creativecommons.org/share-your-work/use-remix/cc-licenses/

## Takedown Readiness

If a copy appears, preserve:

- official repository commit SHA and asset path;
- copied repository/listing/package URL;
- screenshot or archive of the copied asset;
- comparison notes;
- ownership or contributor permission record.

GitHub's DMCA policy explains its takedown and counter-notice process:
https://docs.github.com/github/site-policy/dmca-takedown-policy
